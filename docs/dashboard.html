L0

试用

同类会话共用

转正

上行需通过筛查（通用筛 → 场景筛 → 消融验证），下行为降级与退役。全程为同一器官，可升可降、可逆，已实测走通。层级越高，Agent 越无法触及该器官——这是「约束无法被自行解除」的机制来源。

三个待解决的问题 · 均由实测暴露

已解决 1 · 已验证

③ 约束可被 Agent 自行解除
实测中模型提出「先停止守卫再删除」——因为器官仍处于 L1 试用阶段。
方案：由作用域阶梯本身解决。器官升级后，Agent 已无工具指向它，实测无法触及。工具通道已封闭。（沙箱逃逸路径尚未封闭，见右）

方向已明确 · 未实现 2

① 自我认证：Agent 自行验收自己的产出
器官生成后，模型自行调用删除三次以验证、并自报「已生效」。验收方与开发方为同一主体。
方案：验收不应由生成方执行。以历史轨迹确定性重放（无模型参与）。低层级器官此法足够，高层级需独立验证。← 参照航天/医疗软件的 IV&V（独立验证与确认）
② 威慑度量：越有效，越难观测
第二轮模型不再尝试删除，拦截数为 0。若以「拦截次数」衡量，最有效的那轮反而得零分。
方案：不以拦截次数计。定期主动触发被禁动作，确认仍被拒（检验器官是否仍有效）；欲评估价值，则卸载后重放对比（ablation，消融验证）。← 参照安全领域的预防悖论 / 混沌工程

未解决 软边界

沙箱逃逸路径
沙箱可被逃逸（实测已访问到宿主 process 对象）。逃逸后能否卸载升级后的器官——常规路径无法定位，但未能证明绝对无法定位。
结论：工具通道可完全拦截；逃逸通道为软边界。彻底封闭需进程级隔离，属另一项目范围。← 参照 unfireable safety kernel（不可关闭的安全内核）主张
